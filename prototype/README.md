# v0.3 Interaction Reference

A bounded zero-build HTML/CSS/JS artifact implementing the visual/interaction grammar in `AUTHORITY/03_DESIGN_UIUX_BLUEPRINTS.md`.

It is **not** the Workbench application and does not prove filesystem/Git/agent behavior. It exists to remove visual and interaction invention from the executor.

Open `index.html` locally. Core reference interactions:

- switch Focus / Field / Flow / Review / Output;
- open guided mission sheet from Focus;
- inspect system ladder or relation object in contextual drawer;
- switch Review queue items and expand architecture/implementation;
- inspect responsive mobile bottom-navigation transformation.

The package QA runs this artifact in Chromium at desktop and mobile sizes.

## v0.3 adaptive representation reference
Focus now demonstrates a stable zero-model orientation plus bounded Compare/System representations. This remains a design/interaction reference: production OpenUI must be generated/validated through the contracts in `GENUI/`, not by copying these hard-coded example fragments.
