# Mozare Compile Authority

1. Classify input as owner-locked, accepted target, current truth, evidence, proposal, claim, historical, or unknown.
2. Freeze `DEC-*` and `HZN-*` before implementation choices.
3. Model actors, semantic objects, commands, lifecycles, surfaces, dependencies.
4. Compile consequence classes as `SCN-*`; combine cases only when product/user/recovery/security/design consequences are materially identical.
5. Attach actual surface/anatomy/copy/responsive/accessibility behavior to each user-visible critical case.
6. Separate reversible defaults from owner-only decisions.
7. Output durable authority; do not leave product meaning for coding agent improvisation.

Do not use test/current implementation as product authority by default. Do not enumerate combinatorics for its own sake.
